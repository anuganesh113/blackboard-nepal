# Screenshots Organization Guide

## Folder Structure

```
screenshots/
├── old/
│   ├── dashboard/          # Old dashboard screenshots
│   └── other-pages/        # Old screenshots for other pages
└── new/
    ├── dashboard/          # New dashboard screenshots
    └── other-pages/        # New screenshots for other pages
```

## Recommended Screenshot Names

### Dashboard
- `dashboard-full.png` - Full dashboard view
- `dashboard-mobile.png` - Mobile view
- `dashboard-tablet.png` - Tablet view
- `dashboard-dark-mode.png` - Dark mode view

### Other Pages
- `batches.png`
- `subjects.png`
- `teachers.png`
- `classrooms.png`
- `students.png`
- etc.

## How to Add Screenshots

1. Place old design screenshots in `old/` folders
2. Place new design screenshots in `new/` folders
3. Use descriptive filenames
4. Ensure screenshots are clear and high-quality
