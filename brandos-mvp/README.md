# BrandOS MVP - Living Brand System

## 🚀 Revolutionary Concept: Living Brands

BrandOS is **not just another logo maker**. It's the world's first **Living Brand System** that creates brands that evolve, adapt, and learn - just like your business does.

### What Makes BrandOS Different?

Unlike static brand generators (BrandCrowd, Canva, Looka), BrandOS creates:
- **Living Brands** that evolve based on performance data
- **Adaptive Designs** that change for different contexts (dark mode, seasons, platforms)
- **AI-Powered Learning** that improves your brand over time
- **Performance Tracking** to measure brand effectiveness

## 🏃 Getting Started

### Prerequisites
- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
cd brandos-mvp
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
# or on a different port
PORT=3001 npm run dev
```

4. Open your browser and navigate to:
```
http://localhost:3000
# or if using different port
http://localhost:3001
```

## 🎨 Using the MVP

### Creating Your First Living Brand:

1. **Start on Landing Page**
   - Click "Create Living Brand" button
   - Review the unique features

2. **Complete Brand DNA Wizard**
   - **Step 1: Identity** - Enter brand name, mission, values
   - **Step 2: Market** - Select industry and target audience
   - **Step 3: Style** - Choose colors and visual preferences
   - **Step 4: Personality** - Define brand traits and voice
   - **Step 5: Behaviors** - Configure living brand features (unique!)
   - **Step 6: Review** - Confirm and generate

3. **Explore Dashboard**
   - View brand health score
   - Check evolution timeline
   - Manage brand assets
   - Monitor adaptations
