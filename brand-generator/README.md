# Brand.js - Brand as Code Generator

A modern alternative to BrandCrowd that focuses on generating **Design Systems** rather than just static logos.

## How it works
1. **Input:** Enter your brand name and industry.
2. **Generate:** The system algorithmically pairs colors and fonts based on the "vibe" of the industry.
3. **Export:** It outputs a visual identity AND a code snippet (`theme` object) ready to be pasted into a React/Tailwind project.

## Tech Stack
- React + Vite
- Tailwind CSS
- Framer Motion (for animations)
- Lucide React (for icons)

## Running locally
1. `npm install`
2. `npm run dev`
