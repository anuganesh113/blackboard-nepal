- Brand name, tagline

- Core values selection

#### Step 2: Market Position  
- Industry selection
- Target audience

- Unique differentiator

#### Step 3: Visual Style
- Color personality
- Shape language
- Typography selection
- Style attributes (minimalism, friendliness, etc.)

#### Step 4: Personality
- Brand traits (up to 4)
- Voice & tone
- Communication style sliders

#### Step 5: **Living Behaviors** (UNIQUE!)
This is our secret sauce - no competitor has this:
- **Seasonal Adaptation**: Auto-adjusts for holidays
- **Contextual Optimization**: Adapts to dark mode
- **Platform Optimization**: Different per platform
- **Performance Evolution**: Learns from data
- **Evolution Settings**: Control adaptation rate

#### Step 6: Review & Generate
- Summary of all choices
- Living brand preview
- Generation simulation

## 🚀 How to Run the MVP

### Quick Start:
```bash
cd /workspace/brandos-mvp
./start.sh
```

### Manual Start:
```bash
cd /workspace/brandos-mvp
npm install
npm run dev
```

Access at: **http://localhost:3000** (or 3001 if port is busy)

### Key URLs:
- Landing: http://localhost:3000
- Create Brand: http://localhost:3000/create  
- Dashboard: http://localhost:3000/dashboard
